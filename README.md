# BIT 2118 – Scientific Computing

## Project Overview

This repository contains Python programs and supporting documentation prepared for the BIT 2118 Scientific Computing assignment. It includes original exercises, parameter-change comparisons, and applications of numerical methods to real-world scenarios.

The programs are organized by Parts A–S, corresponding to Tasks 2–20.

## Repository Contents

| File or folder | Description |
|---|---|
| `Original Programs/` | Python programs for the original assignment exercises |
| `Parameter Change Programs/` | Versions of the exercises with selected input parameters changed |
| `Modified Case Programs/` | Programs applying the methods to practical, assumed scenarios |
| `01_Inputs_Operations_and_Output_Meaning.md` | Inputs, mathematical operations, parameter changes, and output interpretations |
| `02_Modified_Case_Assumptions.md` | Assumptions, sample inputs, outputs, and interpretations for the modified cases |
| [`Project Documentation.pdf`](Project%20Documentation.pdf) | PDF summary of the assignment and its results |
